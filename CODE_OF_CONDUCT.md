# Code de conduite

Nous nous engageons à offrir un espace respectueux et accueillant. Sont attendus : la courtoisie, la critique constructive, l'attention aux débutants. Sont inacceptables : le harcèlement, les propos discriminatoires, la divulgation de données privées.

Les comportements inacceptables peuvent être signalés via un avis privé sur le dépôt. Les mainteneurs peuvent modérer ou retirer toute contribution qui ne respecte pas ce code. Adapté du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/) v2.1.
