# Vigie

Inventaire de sécurité de tes comptes, **local et chiffré** (macOS). Détecte les risques, calcule un score explicable et te dit quoi corriger en premier.

> Projet en développement : voir [docs/PLAN.md](docs/PLAN.md).

## Développement

Prérequis : Rust (rustup), Node 22+.

```sh
npm install
npm run tauri dev
```

Tests : `cd src-tauri && cargo test` · `npm test`.
